# Hunch on Robinhood Chain

Prediction markets on Robinhood Stock Tokens that pay an early call more than a late one,
and stay open until the closing bell. USDG stakes, Chainlink settlement, chain 4663.

The build spec is in [`docs/spec/`](docs/spec/00-README.md). This README is rewritten as the
product lands; nothing here is a claim that anything is live.
