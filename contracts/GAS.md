# VPM reference contract: measured gas

Generated by `forge test --match-contract GasTest -vv` (test/Gas.t.sol), which rewrites this file.

- solc 0.8.28, optimizer on, 200 runs, `via_ir = false`, EVM `cancun` (see foundry.toml)
- Every figure is a `gasleft()` delta around a single external call with the contract and token storage COOLED first (`vm.cool`), i.e. the execution cost of that call as its own transaction. It excludes the 21,000 base fee and calldata, and includes the mock ERC-20 transfer inside the call.
- kappa = 9, symmetric seed of 5,000 units per leg, stakes of 1,000 units unless stated.
